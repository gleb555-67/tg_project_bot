## 📌 О проекте

**Telegram Project Bot** — это удобный Telegram-бот, который помогает вам вести портфолио своих проектов.  
Вы можете добавлять проекты, указывать их статус, описание, ссылки, а также привязывать навыки.  
Бот хранит все данные в локальной базе SQLite и предоставляет простой интерфейс для управления.

### ✨ Основные возможности

- 📁 **Добавление проектов** – название, ссылка, статус (из предустановленного списка)
- 🛠 **Привязка навыков** – к каждому проекту можно добавить несколько навыков (Python, SQL, API и т.д.)
- 📊 **Просмотр всех проектов** – список с инлайн-кнопками для быстрого получения детальной информации
- 🔄 **Обновление данных** – изменение имени, описания, ссылки или статуса проекта
- 🗑 **Удаление проектов** – одним нажатием
- 🔍 **Быстрый поиск** – просто введите название проекта в чат, и бот покажет всю информацию
